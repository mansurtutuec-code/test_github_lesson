репо (репозиторий) - Это проект с гитхаба в котором есть файл вашего кода
коммит - Это сохранение вашего проекта на этой стадии (скриншот вашего кода)
ветка - Это пространтво на котором работают программисты



Инициализировать гит в наше проект
>>> git init

Посмотреть версию гита
git version

Нам в компьютер установить базовые настройки почты и логина для гита
git config --global user.name "Ваш логин с гитхаба"
git config --global user.email "Емаил вашего гитхаба"


Чтобы посмотреть на настройки ваших конфигов с пк для гита
git config --global --list


Перемещение по папкам
cd название_папки

Как выйти из папки
cd ..

Как посмотреть на содержимое папки
WINDOWS > dir
MACOS/LINUS > ls


Чтобы добавить все измененные или даже не измененные файлы в индекс для коммита чтобы он сохранил эти файлы в определенной версии
git add .

Чтобы закомитить проект (сохранить его стадию)
git commit -m 'название коммита'

отправить коммит на гитхаб с помощью команды
git push
